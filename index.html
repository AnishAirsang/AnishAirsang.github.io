host-inspector

Repository

A modular user-space diagnostic utility written in modern C++17. Features a real-time CPU utilization speedometer computing work-tick deltas from /proc/stat across a 200ms sample window, 1m/5m/15m load averages from /proc/loadavg, and memory counters from /proc/meminfo. Built with strict CMake targets and modular collector separation.

C++17 Linux procfs CMake RAII File I/O Thread Sleep Delta
