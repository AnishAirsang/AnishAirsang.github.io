host-inspector v2.2 • Active

A modular C++ command-line tool for Linux host diagnostics. Extracts 1m, 5m, and 15m system load from /proc/loadavg, samples /proc/stat clock ticks across a 200ms delta to calculate instantaneous CPU utilization percentage, and parses memory metrics from /proc/meminfo. Built with strict CMake warning targets and RAII stream handling.

C++17 Linux procfs CMake POSIX
